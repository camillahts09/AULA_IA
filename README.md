# Gestão de Pessoas

Sistema CRUD de cadastro de pessoas com HTML, CSS e JavaScript, integrado ao Supabase.

## Funcionalidades
- Cadastrar, editar e excluir pessoas
- Máscara de data DD/MM/AAAA
- Busca em tempo real
- Tema claro/escuro
- Interface glassmorphism responsiva

## Tecnologias
- HTML5 / CSS3 / JavaScript (ES Modules)
- Supabase (PostgreSQL)
- RemixIcon + Google Fonts
